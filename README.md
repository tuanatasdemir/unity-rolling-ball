# Rolling Ball Game 
Unity oyun motoru ve C# kullanılarak geliştirilmiş, fizik tabanlı bir 3D platform oyunu. Bu proje, Unity'nin temel mekaniklerini (Fizik, Input System, UI, Sahne Yönetimi) öğrenmek amacıyla geliştirilmiştir.

### Özellikler ###
Fizik Tabanlı Hareket: Rigidbody kullanılarak gerçekçi top fiziği.

Toplama Sistemi: Oyuncu sahnedeki "Yem" küplerini toplayarak puan kazanır.

Kazanma/Kaybetme Döngüsü:

Tüm yemler toplanınca oyun durur ve kazanma ekranı gelir.

Zeminden düşüldüğünde bölüm yeniden başlar.

Zıplama Mekaniği: Space tuşu ile zıplama (Sadece yerdeyken zıplanabilir, sonsuz zıplama engellenmiştir).

Kamera Takibi: Kamera oyuncuyu yumuşak bir şekilde takip eder.

UI (Arayüz): Anlık skor takibi ve "Kazandın" mesajı.
